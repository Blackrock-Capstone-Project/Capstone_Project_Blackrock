# NYSE 日频实验结果

本目录是历史实验快照；对应研究 notebook 已退出项目。当前数据入口见仓库 README。

- 实际扫描 NYSE：1,539,605 行、1,502只股票、1,202个交易日，无重复股票日期键。
- 筛选后：训练780,632行，验证322,245行，测试252,433行。
- 两个基线、六个模型均使用相同评价样本；验证集选择 XGBoost，测试 MAE 124,990股，相对mean20改善25.5%。测试表中Lasso的MAE略低，不能据此宣称树模型占优。
- 12个代码单元从干净kernel顺序执行，无异常或警告。Notebook内部记录运行时间 87.4 秒（不包括kernel启动和外部核验）。
- 保存的4,597,424条验证/测试预测已分块重新计算全部16组MAE/RMSE，和metrics一致；非负、有限值、反变换和截止日检查通过。
- Data目录9,108个文件的大小和修改时间与执行前一致；未修改已有数据。
- 已检查四张图；缺失案例日期留空。NumPy2.2.1的矩阵数值警告经过逐项求和对照后，在2.3.5下重新执行消除，结果保持一致至浮点误差。

`daily_predictions.csv.gz`约157MB，保存在本地且不纳入Git。cluster及intraday尚未实现。现有股数调整和居中清理使用事后信息，本实验不是严格历史时点回测。
