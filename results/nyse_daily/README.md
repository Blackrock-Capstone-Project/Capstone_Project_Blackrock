# NYSE 日频预测：WRDS 数据刷新结果

本目录是历史实验快照；对应研究 notebook 已退出项目。当前数据入口见仓库 README。

## 数据与样本

- 独立扫描新增日频：9,912,832行、12,975个证券、1,202个交易日，无重复security_id-date键。
- 全部类型NYSE行3,745,710；研究范围为普通股/普通ADR。其历史NYSE候选为2,431,680行、2,636个证券。
- 筛选后2,145,529行、2,564个证券：训练1,327,140，验证464,062，测试354,327。
- 至少60条历史，滚动使用有效观测。236,044条纳入记录的过去60行竞价标签不足60个；不会再因单日缺失连删60条后续记录。
- MCK的2026-06-22竞价标签仍缺失，不造标签；6月23日至9月16日的60条原先被排除记录已恢复预测。见mck_gap_check.csv和案例图。
- 独立XNYS日历核对无缺失/多余交易日，报告在 `results/nyse_daily_refresh_inspection/`。

## 预测结果

验证集选出XGBoost，测试MAE 111,495股，相对本版mean20的153,808股改善27.5%。Lasso测试MAE 112,503股；线性模型RMSE低于XGBoost，所以不声称树模型在所有指标占优。

`metrics.csv` 是主指标表；`size_group_metrics.csv` 和 `stock_mae.csv` 是分层诊断。`previous_run_comparison.csv` 对照旧版，但股票池、来源和历史筛选都改变，不能将误差降低单独归因于补齐数据。旧版小型结果在 `results/nyse_daily_before_refresh/`。

- Data目录9,240个文件的大小与修改时间保持不变；原始数据、processed文件及既有处理脚本未修改。
- 检查5张图；案例图按市场日期留空，不跨缺口连接。MCK长段空白已消失，缺失目标当日仍留空。

逐日预测文件约281MB，保留本地且不纳入Git。最新股本统一使用样本末端AJEXDI参考因子，仍有事后口径；符号连接不是官方永久TAQ映射。cluster与intraday尚未实现，日内量未来需按本版映射/股本口径重建后衔接。

## 逐股票评价后的模型推荐

新增逐证券MAE/Skill分布、配对胜率和差值、观测长度敏感性。按验证期股票等权MAE选择后仍推荐XGBoost：测试等权MAE111,842股，典型股票相对基线改善28.5%，约95.0%的可计算Skill股票优于基线。LightGBM接近，Ridge/OLS的RMSE较低。完整结果和结论见 [逐股票模型选择](stock_model_selection.md)。本轮未重调参数，也没有依据测试集改选择；同一测试期先前已被查看，结论属于探索性复核。
