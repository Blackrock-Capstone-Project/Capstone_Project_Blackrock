# NYSE 收盘竞价预测：实验报告

这份报告从数据文件开始，按顺序说明模型怎样得到训练数据、使用了哪些特征、怎样训练和比较，最后解释目前的测试结果。图表和逐项统计可在 [结果 Notebook](../output/jupyter-notebook/nyse_model_results.ipynb) 查看。

## 1. 我们要预测什么？

主要目标是预测一只股票在交易日 **t** 的最终收盘竞价成交股数。当前使用的 `auction_volume` 来自 WRDS TAQ 日度汇总中的 condition 6 收盘成交记录。处理脚本读取已有的 TAQ 汇总字段，不会重新解析逐笔成交。

没有观测到 condition 6 标签时，目标保留为空，不能当作零成交。模型只用有实际正成交量的股票日训练和评分。

六个盘中 checkpoint 是 10:00、12:00、14:00、15:00、15:30 和 15:50（美东时间）。这里的“七个量”不是把六个 checkpoint 加在一起：它们是七个分开的预测目标——一个是当天最终 auction volume，另外六个分别是六个时点的累计成交量。Ridge 为这七个目标各训练一个模型。

盘中更新时，目标仍是当天最终 auction volume，但输入会随时间增加：先用历史比例推算；再用当天实际 checkpoint 成交量直接预测；或者根据实际 checkpoint 与开盘前预测之间的差距，修正开盘前的最终竞价预测。这三种方法已经在本次实验中运行并评分。

## 2. 使用了哪些数据？

处理过程只读取项目现有文件：

- WRDS TAQ 的 NYSE 日度汇总文件：提供 condition 6 标签、六个 checkpoint 和半日市信息。
- Bloomberg 日线：提供价格、全天成交量、成交额和市值字段。
- 当前交易所名单：用于选择和匹配 NYSE 股票。
- 项目里的美国指数重构日历：用于排除重构实施日。

每一行是一只股票在它自己有数据期间的一个交易日，不会人为补出上市前或记录期外的股票日。此次得到 **1,632,823 个股票日、1,506 只当前名单中的 NYSE 股票**，日期范围为 2022-01-03 至 2026-10-16。原始文件没有被修改，也没有补下载数据。

处理表里有 **1,500,166 个正的 condition 6 标签**。其余 132,657 个股票日缺少可用标签，原因是：

- TAQ 日期文件里没有该股票的行：67,717。
- 整个 TAQ 日期文件缺失：34,486。
- 有 TAQ 股票行，但没有 condition 6 标签：30,454。

这些缺口没有用零、前一天或附近日期填补。

## 3. 从文件到模型，处理顺序是什么？

### 第一步：整理 NYSE 股票日

从当前 NYSE 名单读取股票代码，把 TAQ 和 Bloomberg 记录按股票代码和日期对齐。无法识别的代码、缺文件、重复冲突和缺标签都记入审计文件，便于之后查原因。

### 第二步：排除指数重构日

当前版本把项目日历中与数据重合的 44 个重构日从样本中移除，所以这些日期不会成为预测目标，也不会进入 auction/checkpoint 的历史成交量均值和比例。价格特征也采用了严格排除：代码把重构日以及其后一个交易日相关的收益记为缺失。

这个严格规则的代价是：重构日后的第一个交易日，价格特征只能使用重构日前最近一个合格日的数据；重构日和后一个交易日的收益也不进入滚动特征。为避免这些空缺让整段 20/60 日统计都失效，滚动计算要求窗口内有足够比例的真实收益（至少 75%）。本报告的结果都对应这套严格排除规则。

### 第三步：按预测时点构造特征

开盘前特征只使用预测日前已经有的数据。价格和市值若在前一个合格交易日缺失，就向前找最近一次有效值，最多沿用 5 个合格交易日；再旧就留空。成交量和成交额若缺失，用此前 5 个合格交易日的中位数补，至少要有 3 个有效值。四种补值情况都有单独标记。收益率只根据真实价格计算；历史不足或价格缺失时就留空，不用补出来的价格制造收益。由于严格排除重构日及其后一个交易日的收益，滚动的 5/20 日动量和 20/60 日波动率分别要求窗口内至少有 4/5、15/20、15/20、45/60 个真实有效收益；达不到就留空。历史滚动值只向过去计算，缺失标签不当作零。

在当前建模表中，收盘价补值触发 47,772 个股票日（2.9%），市值补值 40,161 个（2.5%），成交量和成交额各补值 41,977 个（2.6%）。按上述有效观测门槛计算后，5 日动量、20 日动量、20 日波动率和 60 日波动率的可用率分别约为 87.2%、95.5%、95.5% 和 96.3%。

TAQ 的当日 checkpoint 不能进入开盘前特征；到达某个 checkpoint 后，盘中模型才可以使用该时点的实际累计成交量。本次模型没有使用 TAQ `continuous_volume`，也没有把它和 auction volume 相加。日成交量特征取滞后的 Bloomberg `PX_VOLUME`；TAQ checkpoint 和最终 auction 标签分别保留。

### 第四步：按日期切分

不随机打乱股票日，而按完整交易日期先后，约按 70%/15%/15% 划分：

- 训练期：2022-01-03 至 2025-05-09，共 1,115,788 个股票日，其中 1,015,064 个有最终竞价标签。
- 验证期：2025-05-12 至 2026-01-27，共 253,142 个股票日，其中 235,521 个有最终竞价标签。
- 测试期：2026-01-28 至 2026-10-16，共 263,893 个股票日，其中 249,581 个有最终竞价标签。

最终测试模型在测试期开始前，用训练期和验证期的数据重新拟合。测试期只用来评分。验证期还用于训练盘中预测误差修正方法。`log1p(股数)` 是 `ln(1 + 股数)`，用来缓和成交量的长尾；它不是把数据缩放到 0–1，预测后再转换回股数。

### 第五步：只在可用训练数据上处理特征

每次训练时，连续特征的截尾边界、剩余缺失值的填补数值和标准化参数都只从当次训练窗口计算，再应用到之后的日期。连续特征按训练窗口的 0.5% 和 99.5% 分位数截尾。上一步按字段规则处理后仍缺失的输入，最后才用训练窗口中位数兜底，并附加缺失标记；标签和 checkpoint 不这样填补：缺失的最终标签不参与该目标的训练，缺失的 checkpoint 不参与对应时点的训练或评分。

## 5. 模型是怎样训练和比较的？

### 开盘前最终竞价量

先用“最近一次有效竞价量”作简单基准：今天的预测值等于这只股票最近一次有记录的最终竞价量。然后用 Ridge、XGBoost、LightGBM、CatBoost 和 scikit-learn 的 HistGradientBoosting 预测最终竞价量。Ridge 还分别预测六个 checkpoint，形成七个开盘前预测目标；树模型本轮只预测最终竞价量。

树模型每次最多从当时可用的训练股票日中抽取 250,000 行；测试股票日全部保留。模型使用固定的一组参数完成第一轮比较，没有做大规模调参。另有一版把训练标签的高端值截尾，仅用于检查极端标签是否明显影响结果；测试时仍按未截尾标签评分。

### 季度扩展训练

为模拟新数据逐步到来，测试期按季度重训最终竞价量模型。每次只用本季度开始之前已经有标签的数据，测试完一季后，上一季的真实标签才进入下一季训练：

| 预测季度                      | 训练数据截至 | 训练标签数 | 本季度测试股票日 |
| ----------------------------- | ------------ | ---------: | ---------------: |
| 2026 年第一季度（1/28–3/31）  | 2026-01-27   |  1,250,585 |           61,270 |
| 2026 年第二季度（4/1–6/30）   | 2026-03-31   |  1,309,661 |           90,060 |
| 2026 年第三季度（7/1–9/30）   | 2026-06-30   |  1,393,487 |           94,494 |
| 2026 年第四季度（10/1–10/16） | 2026-09-30   |  1,482,742 |           18,069 |

最后一个季度只到 10 月 16 日，因为这是目前数据的结束日期。季度回测包含 Ridge 和树模型；每次训练的树模型仍最多抽取 250,000 行。这是每季重训一次的模拟，不是每日重训。

本轮还加了一个“相似股票分组”对照：每季开始时，只用此前已经形成的股票特征给股票做 K-means 分组，再把分组编号作为 Ridge 的额外输入。分组参考过去竞价量和 checkpoint 的水平、竞价量与盘中量的比例、市值和波动率；候选组数为 2 至 8，按轮廓系数选出较合适的一组。模型不使用未来季度的成交量或标签来分组。每季得到的组别固定用于该季预测，并和普通季度 Ridge 在相同股票日上比较。各季度采用的组数和分组质量会在结果表及审计记录中列出。

### 盘中更新

六个时点都预测同一个结果：当天最终 auction volume。比较三种更新方式：

1. **历史比例：**把当天 checkpoint 的累计成交量乘以这只股票过去常见的“最终竞价量 / checkpoint 成交量”比例。
2. **实际 checkpoint 直接更新：**把当天已经看到的累计成交量和开盘前特征一起输入 Ridge，直接预测最终竞价量。
3. **预测误差修正：**开盘前先预测 checkpoint 和最终竞价量；盘中看实际 checkpoint 与预测的差异，再用验证期学到的误差关系修正最终预测。

这三种更新方法都已实际产生测试预测和指标，不是留待以后再做。结果表显示，误差修正在六个 checkpoint 上的 log RMSE 均略低于直接更新。

## 6. 最终结果

### 开盘前预测：固定切分

测试期有 249,581 个正的最终竞价标签。为了让简单基准和模型在完全相同的股票日上比较，固定切分的共同评分样本是 **249,502 行**；其余 79 行没有可用的历史竞价量基准。

`log RMSE` 是 `log1p(股数)` 尺度上的均方根误差。股数 RMSE 和 MAE 则把预测还原成股数后计算。所有方法使用同一批测试股票日：

### 盘中更新：三种方法都预测当天最终竞价量

## 7. 误差大约占实际成交量多少？

要把误差放回实际成交量的尺度理解，不能只看一个 RMSE：

- XGBoost 的 `log RMSE` 是 **0.3903**。对应的 log MSE 约为 **0.1523**；这两个数是在对数尺度上计算的，**0.3903 不是 39% 的误差**。
- 还原成股数后，XGBoost 的 RMSE 约 **434,309 股**，MAE 约 **100,767 股**。RMSE 会把极少数超大误差平方放大。
- 在同一批测试股票日里，实际竞价量平均约 **351,380 股**，中位数约 **151,984 股**，第 90 百分位约 **854,031 股**，第 95 百分位约 **1,328,559 股**。XGBoost 的股数 RMSE 除以平均实际量约为 **124%**，但这个比值不是“平均错了这么多百分比”。

更直观的总量比例是 WAPE：把所有股票日的绝对误差加起来，再除以这些股票日的实际竞价量总和。共同测试样本上的 WAPE 为：最近一次竞价量基准 **38.1%**，Ridge **30.3%**，XGBoost **28.7%**，LightGBM **28.8%**。XGBoost 的逐股票日绝对百分比误差中位数为 **21.7%**。

因此模型确实优于“沿用上次竞价量”，但最佳模型仍有约 **28.7%** 的总量加权绝对误差，预测还不算精确。XGBoost 的平均预测约 **314,145 股**，低于实际平均值，说明模型对高成交量股票日仍可能偏低。

MSE 的单位是“股数平方”或“对数误差平方”，本身不能直接换算成占实际成交量的百分比。要回答“总误差占成交量多少”，本报告用 WAPE；要了解典型股票日的相对误差，可看绝对百分比误差中位数。

## 8. 怎样理解这些结果？

- **模型比简单基准好。**固定切分下，最近一次竞价量的 log RMSE 是 0.4987，XGBoost 降到 0.3903；WAPE 从 38.1% 降到 28.7%。
- **几种树模型成绩接近。**固定测试集上 XGBoost 的 log RMSE 最低；LightGBM 和 HistGradientBoosting 很接近。不能仅凭这点说模型已经调到最好，因为本轮没有做大规模参数搜索。
- **季度扩展训练表现相似。**每季重训后 XGBoost 的 log RMSE 为 0.3896，和固定切分的结果相差很小。扩展训练模拟了新标签逐季加入，但本轮没有看到巨大的改善。
- **K-means 分组没有带来稳定收益。**四季中选出 2 或 3 个组，加入分组后的整体 log RMSE 只从 0.3999 变为 0.3998，MAE 反而略高；目前更适合把它看作一次对照实验，而不是保留为默认模型。
- **盘中信息能继续改善预测。**预测误差修正法的 log RMSE 从 10:00 的 0.3894 降到 15:50 的 0.3797；它在六个时点都略好于直接更新。历史比例法的误差明显较高。
- **结果仍有不确定性。**测试期只有一个连续时间段；本轮没有做不同年份/市场状态下的多次检验或显著性检验。因此这些结果能帮助选择下一步实验，不能据此断言差异一定能长期保持。

## 9. 当前仍需注意的地方

1. TAQ 的 condition 6 是当前采用的候选收盘竞价标签口径；本处理脚本使用现有日度汇总，没有重新从逐笔记录核验所有交易更正和报告场所规则。
2. 股票名单按当前 Bloomberg 分组生成，未完整还原每一天当时的在市股票，因此存在历史样本不完整的可能。
3. Bloomberg 文件没有保留当时的拆股调整设置。特征按预测日之前取值，但不能声称所有历史股数都已经按当时可见口径重估。
4. 指数重构日按项目现有日历排除；月度期权到期特征也按当前代码的日历规则生成。
5. 本轮包括建模表、时间切分、基准模型、七个 Ridge 预测目标、最终 auction 的树模型、三种 checkpoint 盘中更新、季度扩展回测，以及按季度更新的 K-means 分组 Ridge 对照。没有做逐日重训，扩展窗口目前是每季度重训一次。
