## Context

当前 daily 脚本按月下载 Compustat，已具备文件指纹、历史 ticker/交易所、交易日和字段质量校验，但结束日期固定，认证依赖本地配置并有个人账号默认值。TAQ 脚本按日查询、服务端聚合，凭文件存在跳过，账号硬编码，交易日与半日市处理尚未统一。旧 `process_us_taq_data.py` 仍读取 Bloomberg。新模块面向项目研究者，使用各自 WRDS 权限与本地存储。

## Goals / Non-Goals

**Goals:**
- 一个可导入方法与等价 CLI，覆盖首次回填和后续更新。
- 起点默认 2022-01-03；日频和 TAQ 独立发现可用日期，明确缺失及共同覆盖。
- WRDS-only、可恢复、可审计的 raw → processed 流程，交互认证且不记录个人身份信息。

**Non-Goals:**
- 不改模型、滞后特征、训练切分、回归或评估口径，不将数据更新自动扩展为训练。
- 不下载完整 TAQ 逐笔存档；继续获取服务端日内检查点及竞价汇总。
- 不自动保存密码、不自动批准 Duo、不提供定时调度服务，仅删除迁移清单指定的旧数据与 notebook，不清理 Git 历史。
- 不声称 ticker 匹配等于官方永久证券链接，也不声称源表有最新日期就代表所有证券数据完整。

## Decisions

### 1. 统一编排与可复用服务

新增 `scripts/data_pipeline/` 包，以 `update_data(start="2022-01-03", end=None, markets=("NYSE", "NASDAQ"), refresh_sessions=5, ...)` 为公开入口；`python -m scripts.data_pipeline update` 调用同一编排。返回结构化报告，包括来源、请求/实际覆盖、下载/跳过/刷新分区、输出路径、质量问题和成功状态。支持注入连接与认证提供器，便于其他 Python 调用方复用和离线测试。原脚本保留薄 CLI 包装，避免复制下载规则。相比将所有逻辑塞入一个脚本，拆分认证、来源适配器、分区存储、处理和编排便于独立验证。

默认保留现有 NYSE+Nasdaq 范围；按历史交易所提供 NYSE 筛选，不使用 Bloomberg 股票池。配置中保留证券类型，不在下载阶段静默缩小为当前普通股名单。

### 2. 交互认证与受控连接

默认每次建立新会话时询问用户名，密码通过隐藏输入获取；提示用户完成 WRDS 所需的 Duo/登录步骤，使用现有客户端实际支持的认证路径，不模拟或绕过认证。允许调用者提供已有连接或运行时认证提供器，非交互缺少认证时明确失败。只读本地凭证配置必须由用户显式选择；模块不创建 `.pgpass`，不将凭证写入仓库。重连在进程内复用认证上下文，设置超时和有界重试，关闭连接并清理上下文引用。

公开主机、端口可保留为配置；个人用户名、密码、DSN、认证响应不得出现在日志、异常持久化或清单中。通过允许字段列表生成报告并净化异常信息。相比继续使用个人默认账号，此行为支持不同研究者，也满足运行时登录要求。

### 3. 来源和可用范围

固定选择已采用的 `comp_na_daily_all.secd` 和 `sec_idhist`，TAQ 选择对应年份日表；权限不足报告具体来源，不自动换 CRSP/Bloomberg。使用纽约时区和交易日历排除未结束会话及休市日，半日市收盘时间来自日历。探测源表和数据日期，分别报告 daily/TAQ 的已发布范围、内部缺日与共同覆盖。用户明确请求但源端尚不可用的日期保留为 pending，不能记为完整。

### 4. 分区、续传与修订

保留 `Data/raw/wrds/daily/months/` 和 `Data/raw/taq/days/`。每个分区带来源、实际区间、schema/query 版本、行数和 SHA256；只有匹配配置且验证通过才能跳过。旧 TAQ 无元数据的分区先做结构/键/日期校验，标记 provenance 未验证并重取后才成为可信检查点。

每次扫描完整请求区间，补洞并重取损坏分区；默认刷新各来源最新 5 个已发布交易日涉及的分区，支持显式刷新更早范围。daily 月分区扩展时合并所需区间或重取其并集，不能用新片段覆盖旧历史。原始分区以临时文件和原子替换发布，元数据最后写入；并发更新同一数据根目录时采用单写锁或立即拒绝。

按请求区间检查缺失，并按实际查询的 time chunk 建立预期分块清单，逐块记录请求边界、执行状态、返回行数和验证结果；不得仅凭最终文件存在或整体日期首尾覆盖判定完整。核对预期分块与成功分块，检查整块遗漏、块间缺口及块内应有交易日缺失。空块、查询失败和源端确实无记录须分别记录；未经来源可用性或交易日历核实的空块不能标记完成。空交易日结果不自动标记成功；来源无记录与休市必须区分。部分失败保留已验证分区，返回失败/部分完成状态，下次继续补取缺失分块。

### 5. 独立处理与输出契约

沿用 `Data/processed/us_wrds_daily/daily_clean.csv.gz`；新增 `Data/processed/us_wrds_taq/`，保存 `checkpoints_clean.csv.gz`（symbol/date/checkpoint）、`labels_clean.csv.gz`（symbol/date）及 TAQ 日度汇总。daily 主键为 GVKEY/IID/date，保留历史标识、证券类型、价格状态和调整因子；TAQ 仍保留原始 symbol 和交易所推断来源。只生成来源原生的观察数据，不把当日数据当作滞后预测特征。

复用已记录的 Compustat ADR 股数、报价状态和市值口径，以及 TAQ 检查点、竞价条件与场所选择规则，并在实施前用小样本确认；规则发生变化时记录版本并重处理。缺失不填零；无 TAQ 来源的日内收益不伪造；不再使用 Bloomberg 价格推断拆股。输出量价保留原生股本基础和明确单位，跨源匹配/复权仍由下游显式处理，歧义不得强行连接。

提供单独的离线 process/audit 入口；指纹或处理版本变化时重建受影响来源的整套输出，首版优先可靠性，不强求行级增量处理。输入未变则验证并复用。处理到临时版本目录，重新读盘校验后发布，通过完成清单最后写入标记整套产物有效；失败时保留上一有效版本。读取者通过清单和指纹判断有效性。质量报告记录交易日、主键、缺失、检查点合法性及输入指纹。

### 6. 成交量质量与样本筛选

在原生标准化观察表之上新增独立质量层，保留观察值和排除原因，不删除 raw 或覆盖未筛选标准化表。这里的两个 volume 指 Compustat 日频总成交量和 TAQ 收盘竞价成交量；任一值 ≤0、NA（含 NaN/缺记录）或正负无穷，该股票日即为异常。有限且为正只表示通过本规则，不保证没有极端大值；本次不引入未经定义的极值阈值。TAQ 检查点在一天早期可能合法为零，不套用整日成交量规则。

采用永久证券 GVKEY/IID 及已验证的历史 symbol 匹配构造证券日质量网格；匹配歧义保留并报告，不能猜测连接。网格为请求范围与证券有效上市/目标市场区间、daily/TAQ 共同已发布覆盖的交集上的应有交易日。区间内缺失记录计异常；上市前、退市后、休市及尚待发布的日期不计分母。分区损坏/下载未完成须先修复或返回质量未完成，不能当作证券异常导致批量剔除。上市边界应来自可用历史标识的有效区间与上市信息，不以首末非缺失成交量观测冒充，边界无法确定时报告未决，不能默认为合格。

在未经过滤的质量网格上先计算有效日标记，再按交易日历取 t 之前 10 个交易日的有效天数；至少 6 天才取得 t 日横截面资格。缺失日不能从窗口删除后再取最近 10 条记录，也不能把当日值纳入。请求起点或上市初期不足 10 日时按实际可见历史计数，不足 6 天不保留，不使用 60% 比例替代绝对门槛。历史计数独立于当天是否有效，最后可用样本还要求当天有效。

整只股票异常率 = 异常交易日数 / 上述应有交易日数，在行级筛选之前计算；严格 >0.05 才整只剔除，恰好 5% 保留，零分母标为未决。最终样本同时要求整股保留、历史有效天数 ≥6、当天有效及跨源身份无歧义。输出 `Data/processed/us_wrds_quality/stock_day_quality.csv.gz`、`security_quality.csv` 和 `eligible_stock_days.csv.gz`，记录字段级异常原因、滚动计数、分子分母、整股判定、排除原因及规则版本。

增量更新或来源修订可能改变整股判定，须重新计算受影响股票的完整请求历史并更新质量产物指纹。由于使用全历史异常率，质量清单必须写明事后清洗属性及不适用于严格历史时点回测；未来回测需另行按当时可见历史构造股票池。本次不改模型。

### 7. 仓库隐私与迁移

维护 `/Data/` 忽略规则；验证 raw/processed 和认证配置未被跟踪。审查项目源码/文档中的个人账号及连接信息，不读取或输出本机凭证内容。示例只使用运行时提示或占位符。删除 `Data/processed/us/`、`Data/processed/lse/`、`Data/raw/bloomberg/uk/` 及仓库中的研究 `.ipynb`（含对应 checkpoint）。实施前枚举准确路径，删除仅限该清单，不扩大到其他美股 raw 数据、`us_wrds_daily` 或实验结果目录。移除 LSE 和旧混合处理入口及其专属文档；若有共享函数仍被新模块依赖，先迁移必要逻辑再移除旧入口。清理 README 和其他文档中的失效链接，不保留这些对象的仓库内兼容副本。新模块失败时不回退到旧混合来源。

## Risks / Trade-offs

- [用户权限或发布延迟不同] → 逐来源探测、报告 pending/缺口，不夸大全量完成。
- [近期窗口之外的供应商修订] → 可配置刷新区间并记录指纹；默认 5 日不保证捕获全部历史修订。
- [旧 Bloomberg 数据退出后，原生量价口径需明确] → 不保留此前遗留的 Bloomberg 数据，按迁移清单删除并核查残留；新产物仅使用 WRDS，清晰记录单位、股本基础及复权口径。旧模型或 notebook 的迁移不混入本次实现。
- [多年 TAQ 查询成本高，且可能整段 time chunk 漏取] → 服务端汇总、按日续传、有界重试；建立预期查询分块清单，逐块核对请求边界、执行状态、返回行数与应有交易日，检查整块遗漏及块间缺口。未核实的空块或漏块不得标记完整，须补取或报告部分完成；全量运行由用户执行认证后触发。
- [处理期间中断造成混合版本] → 临时输出、清单指纹和上一有效版本保留；消费者验证清单。
- [异常包含连接信息] → 只保存允许字段和净化错误，使用合成敏感字符串测试。
- [全历史剔除使用未来信息且随更新改变历史样本] → 单独保存资格层、规则和输入指纹，明确事后清洗及回测限制。

## Migration Plan

先实现离线可测的认证与分区契约，再接入 daily/TAQ 和 WRDS-only 处理器；用合成分区及可选的小区间真实连接验证，然后更新 CLI/文档。新模块验证后按显式路径清单删除旧 `processed/us`、LSE raw/processed 和研究 notebook，并清理不再使用的入口/文档；不自动全量下载或训练。新模块后续回退只使用自身上一套有效 WRDS 产物，不依赖已删除的混合流程。指定旧数据删除不承诺可恢复，其他美股原始数据和独立 WRDS 产物不在删除范围。

## Open Questions

没有阻塞提案的产品问题。实施时需核对已安装 WRDS 客户端的交互认证/Duo 行为和交易日历覆盖；若其能力不足，应明确报告，不能退回硬编码账号。默认刷新 5 个交易日为可配置的工程默认值。
